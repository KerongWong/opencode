# Phase 2 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**阶段定位：** 「每个本地 checkout 成行」。本 phase 的两个计划已在 `865c92915a` 落地，且**零视觉改动**：`projects.tsx` 只新增一个挂载期 effect（`requestedWorktrees` Set + `worktrees.list`），`projects-groups.ts` 只改纯函数的根集合（`worktrees ∪ sandboxes ∪ worktree`），`projectGroupFor` 的 key 表达式一字未改。因此本契约不引入新视觉，而是把 **Projects 侧栏既有表面的行语义、状态覆盖与不变量** 固定下来，供 planner / executor 续做后续 phase、供 UI 审计对照。

**视觉真源：** `packages/app/src/shell/titlebar/projects.tsx`（组件与全部 class）、`packages/app/src/shell/titlebar/projects-groups.ts`（分组与 key）、`packages/ui/src/styles/tokens/theme.css` + `colors.css`（token 值）、`packages/app/src/runtime/i18n/en.ts` 805–837（文案键原文）。

## Spacing Scale

Declared values（4 的倍数）：

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | 组间距 `mb-1`、组行右侧内边距 `pe-1`、已移除菜单上方 `pt-1`、`gap-1` |
| sm | 8px | 会话行图文间距 `gap-2`、loading 容器 `p-2` |
| md | 16px | 本表面不使用（保留给更大容器） |
| lg | 24px | 本表面不使用 |
| xl | 32px | 组标题行高 `h-8`（行高即主要纵向节奏） |
| 2xl | 48px | 本表面不使用 |
| 3xl | 64px | 本表面不使用 |

Exceptions（**继承自既有表面，本 phase 锁定不改**，不是新增自由度）：

- `2px`：组标题与会话列表之间 `mt-0.5`；组标题行内头像与文字之间 `gap-0.5`（`projects.tsx` 组标题行）。
- `6px`：`px-1.5` / `ps-1.5` / `gap-1.5`（组行与菜单触发的横向内边距、图标与文字间距）。
- `12px`：空态容器的 `py-3`（`projects.tsx` 空态 `px-2 py-3`），与 `px-2`（8px）不对称是既有取值，本 phase 不改。
- `26px`：会话行与 Show more 的 `ps-[26px]`，让会话标题对齐到组标题头像之后；该值与组行图标/头像尺寸绑定，改任一项都会错位。
- `28px`：会话行与 Show more 行高 `h-7`。
- 触控目标：组行 32px、会话行 28px，低于 44px 是既有取值；本 phase 不调整（桌面鼠标为主，行密度是产品决定）。

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body（会话标题、空态、未分组行） | 13px | 400 | 16px（`--line-height-compact`）= 1.23 |
| Label（组标题 / checkout 名） | 14px | 500（`font-medium`） | 16px = 1.14 |
| Meta（Show more、已移除项目菜单触发） | 12px | 400 | 16px = 1.33 |
| Micro（组内会话计数、age） | 11px | 400（`tabular-nums`） | 16px（继承行盒，`--line-height-compact`） |

规则：

- 字号以 Tailwind 任意值写到 class（`text-[13px]`），本项目没有字号 token；**本 phase 不新增字号**。
- `13px` 必须配 `leading-4`（16px）：`packages/ui/AGENTS.md` §Typography 明确禁止 13px 配 1.0 行高（Inter 的 `g j p q y` 会在截断容器里被裁）。
- `tracking-[-0.04px]` 只用于 14px 组标签与 13px 会话标题，两处一致。
- 字重只有 400 与 500 两档；500 仅用于组标题。不要用 600 及以上：Mono 在 ≥600 会切换到 IBM Plex Mono Bold，且本表面不需要更高强调层级。
- 所有可截断文案带 `dir="auto"`（组标签、会话标题），不得写死 `dir="ltr"`。

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--v2-background-bg-deep`（浅 `#fafafa` / 深 `#080808`） | 侧栏底色、列表滚动区；由外壳容器继承，`projects.tsx` 自身不画任何背景 class |
| Secondary (30%) | `--v2-background-bg-layer-02`（浅 `#f2f2f2` / 深 `#2e2e2e`） | 组标题行 `bg-v2-background-bg-layer-02` |
| Accent (10%) | 状态色：info `#3250df`/`#7698fd`、warning `#cb9f34`/`#f2cf76`、danger `#b82d35`/`#f17471`、success `#198b43`/`#6bd586` | **仅**下列状态标记 |
| Destructive | `--v2-state-fg-danger`（`#b82d35` / `#f17471`） | **仅** `sidebar.projects.remove` 菜单项与 `failed` 状态标记 |

Accent reserved for（逐项，禁止扩到「所有可交互元素」）：

1. `working`：会话行 `ActivityRing` 16px、组徽标 `ActivityRing` 12px，颜色 `var(--v2-state-fg-info)`。
2. `approval`：`circle-exclamation` 图标 + warning 组徽标（6px 圆点 + 11px 计数）。
3. `input`：`help` 图标 + warning 组徽标。
4. `failed`：`close` 图标 / danger 圆点；`sidebar.projects.remove` 菜单项文字。
5. `done`：`check` 图标 + success。

非 accent 的中性层（不得换成状态色）：

- hover：`--v2-overlay-simple-overlay-hover`（浅 `#0000000a` / 深 `#ffffff0f`）；pressed/选中：`--v2-overlay-simple-overlay-pressed`（浅 `#00000014` / 深 `#ffffff1a`）。
- 键盘焦点复用 hover overlay（`focus-visible:bg-v2-overlay-simple-overlay-hover`），无独立 focus ring；不要为此新增 outline。
- 正文 `--v2-text-text-base`；次要文字/计数 `--v2-text-text-muted`；图标 `--v2-icon-icon-muted`；分割线 `--v2-border-border-muted`（仅已移除菜单上方的 `border-t`）。

两个必须保留的例外：

- `ActivityRing` 的颜色**必须内联** `style={{ color: "var(--v2-state-fg-info)" }}`：`activity-ring.css` 把颜色写在无 layer 的 `[data-component="activity-ring"]` 规则里，utility 的 `@layer utilities` 永远输给它（设计文档 §已知取舍 2）。改成 class 会让 working 标记失去 info 色。
- 除上述内联 `var(...)` 外不写十六进制颜色。
