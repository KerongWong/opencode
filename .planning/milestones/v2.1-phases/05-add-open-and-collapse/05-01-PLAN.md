    - `awaiting + sessions.ready{attempt 匹配}`：sessions 非空 → `opening`，effects `[watch.stop, open.recent(首条)]`；空 → `opening`，effects `[watch.stop, open.new]`。
    - `awaiting + sessions.ready{attempt 不匹配}` → 原 state、空 effects（陈旧忽略）。
    - `awaiting + watch.timed-out{attempt 匹配}` → `failed`，effects `[watch.stop]`（静默）。
    - `opening + opened / open.failed{attempt 匹配}` → `idle` / `failed`；attempt 不匹配忽略。
    - 任意 state + `disposed` → `idle`；awaiting 时 effects 含 `watch.stop`。
    - 不适用的事件（如 idle + sessions.ready）→ 原 state、空 effects。
  </behavior>

    - `export type AddOpenEvent = { type: "registered"; key: string } | { type: "sessions.ready"; attempt: number; sessions: Pick<SessionInfo, "id">[] } | { type: "watch.timed-out"; attempt: number } | { type: "opened"; attempt: number } | { type: "open.failed"; attempt: number } | { type: "disposed" }`（SessionInfo 从 `@opencode/client/promise` 导类型）
